# Bem-vindo(a) ao Meu Repositório de Tutoriais e Scripts

Olá! Sou Márcio, pesquisador de bioinformática. Criei este espaço para compartilhar tutoriais, documentações e scripts focados em análise de dados, genômica, biologia molecular e computação de alta performance.

Aqui você encontrará guias práticos, códigos em Python e R, e dicas para otimizar suas análises no dia a dia da pesquisa.

## 🚀 O que você vai encontrar aqui?

*   **Tutoriais de Ferramentas:** Guias passo a passo para utilizar ferramentas essenciais na pesquisa (como Singularity/Apptainer, MkDocs, etc).
*   **Scripts de Bioinformática:** Snippets e pipelines para análise de dados biológicos, limpeza de matrizes de expressão e visualização de dados.
*   **Dicas de Automação:** Como facilitar o trabalho e garantir a reprodutibilidade das suas análises.
